# CAMPA Fencing Calculator

Fencing material calculator for CAMPA plantation sites, Mohla Forest Division.
Enter a site's area (hectares) or actual perimeter to get total poles, barbed wire (tons),
cement (50 kg bags) and 20 mm aggregate (m³). Includes a site list with totals,
editable norms, and a Hindi / English switch.

It is a single static page (`index.html`), with no build step and no dependencies.

## Deploy on Vercel
1. Upload these files to a new GitHub repository.
2. On vercel.com, choose **Add New → Project** and import that repository.
3. Framework preset: **Other**. Leave Build Command and Output Directory empty.
4. Click **Deploy**.

## Run locally
Open `index.html` in any browser.
